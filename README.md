# 🧀 Cheese Clicker

Pixel-style idle clicker. Click the cheese → cheese coins. Buy cute helpers that earn coins for you.

- **Click**: +1 coin (more with Rat Upgrades)
- **Helpers**: worms, snail, mouse, hamster, bunny… each earns coins/sec
- **PC**: landscape layout, rat cursor (bites on click)
- **Mobile**: portrait layout, no cursor; asks you to turn the phone upright if held sideways
- Progress auto-saves in the browser (localStorage)

Play locally: open `index.html`. No build step.

## Put it online (GitHub Pages)
1. Merge into `main`.
2. Repo **Settings → Pages → Source: GitHub Actions**.
3. The `Deploy to GitHub Pages` workflow publishes it at `https://bugabinga.github.io/CheeseClicker/`.
